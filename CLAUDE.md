# Правила работы в этом проекте

- Правки файлов (Edit/Write) здесь разрешены без подтверждения — настроено в `.claude/settings.local.json`. Единственная страховка от этого — git, поэтому:
- **Перед началом каждого отдельного блока правок сначала закоммить текущее состояние** (`git add -A && git commit -m "..."`), даже если это просто checkpoint незавершённой работы. Это даёт точку отката на случай, если следующий блок правок пойдёт не так.
- `git add`/`git commit`/`git status`/`git diff`/`git log` разрешены без подтверждения. Всё остальное в терминале (`git push`, установка пакетов, запуск собранных .app, удаление файлов) — по-прежнему спрашивает подтверждение, это осознанно.
- Ничего не пушить в удалённый репозиторий без явного запроса.
